# Support

Use the [issue tracker](https://github.com/ricardoleal20/modena/issues) for bug
reports, usage questions, numerical discrepancies, and feature requests. Choose
the matching issue form; a blank issue is available for usage questions.
Search existing issues first, then include the version or commit you used and
a small input or command when relevant. See [contributing](CONTRIBUTING.md)
for reproduction details and development checks.

For sensitive vulnerabilities, follow the [security policy](SECURITY.md).
Community concerns are covered by the [code of conduct](CODE_OF_CONDUCT.md).

MODENA is in early development. There is no guaranteed response time or
production support commitment. Start with the examples and review the
[validation scope](docs/VALIDATED_SCOPE.md) when deciding whether the engine
fits a simulation.
