# MODENA brand assets

The selected identity is **Flow**: three sweeping bands that suggest numerical
trajectories evolving through time. The outer band is mint, with two ivory
bands on deep petroleum ink. The symbol is abstract identity artwork, not a
simulation result, molecular structure, or scientific diagram.

The production assets are raster images. The icon exports preserve the exact
approved artwork and its dark background; they are not transparent cutouts or
editable vector masters. Keep the square icon's padding intact and scale it
proportionally. Avoid stretching, rotation, recoloring, or adding particles.

The banner is designed for full-width display in the README. Keep the text and
symbol visible rather than cropping it into a square. Its copy is also available
as ordinary text in the main README.

## Palette and accessibility

| Color | Hex | Role |
| --- | --- | --- |
| Ink | `#10262B` | Dark identity surface |
| Paper | `#F7FAF8` | Primary lettering and inner bands |
| Mint | `#5ED8C1` | Outer band and inverse accents |
| Teal | `#087F78` | Links and light-surface interface accents |

Use `alt="MODENA"` for an icon that identifies the project. Use empty alt text
when adjacent text already names MODENA. The README banner uses descriptive alt
text. See the [design system](../../DESIGN.md) for interface guidance.
