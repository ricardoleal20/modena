# MODENA 0.1.1

First public prerelease of the Rust molecular dynamics library, CLI, and Python
subprocess client. APIs and input formats may change during early development.

This release incorporates the existing scientific-hardening branch, including
corrections to stochastic sampling, constraint propagation, force-cache
coherence, electrostatic units and virials, and complete checkpoint state.
It adds typed molecular workflows and unconstrained isotropic Monte Carlo NPT.
The [changelog](../../CHANGELOG.md) records the changes from 0.1.0.

The Python client now finds executables in custom Cargo target directories,
cleans up temporary inputs on failures, and preserves CLI errors before parsing
logs. New independent tests check CSVR transition moments, stationary kinetic
energy, and signed single-degree-of-freedom velocity sampling.

## Get started

Use Rust 1.90 or newer and follow the [README](../../README.md). The source
distribution includes the CLI, library, examples, tests, and numerical evidence.
There are no registry packages or prebuilt binary downloads in this release.

## Scope

Focused checks cover selected pair, ionic, and fixed-volume molecular models.
They do not establish converged liquid properties or broad agreement with a
reference engine. Constrained pressure remains diagnostic; constrained NPT and
full anisotropic coupling are rejected. GPU and MPI are restricted experimental
library backends, rather than alternative TOML runner engines.

See [validation scope](../VALIDATED_SCOPE.md),
[release verification](v0.1.1-verification.md), and the historical
[scientific record](../scientific-hardening/RESULTS.md) for methods and limits.

## Compatibility

The real-unit charge normalization changed from 0.1.0. Older real electrostatic
runs with a reference length different from one use a different Hamiltonian.
Normal continuation checks physical identity; state-only import does not
promise continuation of the original trajectory. See
[unit normalization](../scientific-hardening/UNITS.md).

Report bugs with a small input, version, command, and expected behavior through
the [issue tracker](https://github.com/ricardoleal20/modena/issues).
