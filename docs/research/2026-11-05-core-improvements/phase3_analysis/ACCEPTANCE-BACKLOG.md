# Backlog de aceptación del core

Síntesis de investigación, Fase 3; **ningún cambio de esta tabla está implementado o aceptado por este documento**. Identificador local del manifiesto anterior, sin Material Passport ni replay. Base: `f166399070b2d6ebfd91f51e5934c132f04d46c0`; véanse [síntesis y tensiones](SYNTHESIS.md), [verificación de fuentes](../phase2_investigation/SOURCE-VERIFICATION.md) y [casos C1–C5](../phase2_investigation/CASES.md).

**Prioridad condicionada:** P0 establece evidencia; P1 habilita el caso elegido; P2 optimiza después de perfilar; P3 exige necesidad de hardware/escala. **Tamaño relativo:** S, cambio acotado; M, varios módulos; L, contratos y rutas cruzadas; XL, backend/algoritmo con validación extensa. No son duraciones. Cada criterio exige fijar previamente fixtures, tolerancias y precisión en un protocolo; C4/C5 deben fijar material, modelo, pesos y referencia antes de evaluar eficacia química. La paridad de software puede comenzar con fixtures controlados.

Precisión de la revisión final: el vertical mínimo C4 puede admitir solo periodicidad tridimensional. Registrar PBC por eje no implementa por sí solo wrapping, vecinos y electrostática de fronteras parciales; esas combinaciones deben rechazarse hasta tener soporte y pruebas propios.

Ninguna de ellas demuestra una mejora de MODENA.
